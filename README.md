# 📚 Smart Study Planner (Multi-Agent AI System)

## 🚀 Overview

Smart Study Planner is a multi-agent AI system built using Google ADK
that helps students: - Create structured study plans - Automatically
schedule tasks - Track progress

------------------------------------------------------------------------

## 🧠 Architecture

-   **Root Agent (Coordinator)**
-   **Planner Agent** → Generates study plan
-   **Task Agent** → Stores + schedules tasks

------------------------------------------------------------------------

## ✨ Features

-   📚 AI-generated study plans
-   🔥 Priority-based scheduling
-   📅 Calendar integration (mock MCP tool)
-   📊 Progress tracking
-   ✅ Task completion tracking
-   💬 Natural language interface

------------------------------------------------------------------------

## 🛠️ Tech Stack

-   Python
-   Google ADK
-   Gemini 2.5 Flash
-   SQLite
-   Google Cloud Run
